# FitMind AI — Full Stack + Real AI Agent

A real frontend + backend + a genuine local-LLM coaching agent. The backend is a small Express API that computes
live vitals, muscle-activation percentages, and a shared AI coach decision,
and persists scan events to disk (`backend/data/store.json`). The frontend
polls these endpoints instead of faking numbers in the browser.

If the backend isn't running, the frontend still works — it falls back to
local simulation and shows "OFFLINE MODE" in the header pill, so you can
develop/preview either side independently.

## Run it (two terminals)

**Terminal 1 — backend:**
```bash
cd backend
npm install
npm start
```
Runs at `http://localhost:4000`. You should see:
```
FitMind AI backend running at http://localhost:4000
```

**Terminal 2 — AI agent (optional but recommended):**
```bash
# one-time: install Ollama from https://ollama.com/download
ollama pull qwen2.5:0.5b

cd agent
python agent_server.py
```
Runs at `http://localhost:5000`. No pip install needed.
Skip this and the app still runs — the coach just shows
"AI AGENT · OFFLINE" and uses safe defaults.

**Terminal 3 — frontend:**
```bash
cd frontend
python3 -m http.server 8080
```
Open `http://localhost:8080`.

(Or use VS Code's Live Server extension on `frontend/index.html` instead of
the Python server — either works, since it's just static files.)

## What's actually live

- **Header pill** ("LIVE · N SCANS LOGGED") — pulled from `/api/stats`,
  proves the backend is connected and shows real persisted scan counts.
- **Muscle page BPM readout** — polls `/api/vitals` every 1.1s.
- **Muscle page side cards** (activation bars, symmetry ring, pose-confidence
  radar) — polls `/api/muscle-activation` every 2.6s.
- **"Run live scan" button** — POSTs to `/api/scan`, which increments a
  persisted counter in `store.json` and returns a real confidence value used
  to drive the on-screen counter.
- **Fuel page cards** — pull protein/hydration/recovery/absorption from
  `/api/fuel/stats`.
- **Coach page decision** — now generated by the REAL AI agent. The backend
  sends live vitals to the local LLM, which decides what you should do today
  and explains why, referencing your actual numbers.
- **"Ask your coach" chat** (Coach page) — free-form Q&A answered by the
  local LLM, with fitness guardrails.

## API endpoints

| Method | Path                    | What it does                                  |
|--------|--------------------------|------------------------------------------------|
| GET    | `/api/health`            | Basic liveness check                           |
| GET    | `/api/vitals`             | BPM / energy / recovery (server-computed)      |
| GET    | `/api/muscle-activation`  | Per-zone activation % + symmetry + pose conf.  |
| GET    | `/api/coach/decision`     | Current shared AI coach recommendation         |
| GET    | `/api/fuel/stats`         | Protein / hydration / recovery / absorption    |
| POST   | `/api/scan`               | Logs a scan event, returns updated confidence  |
| GET    | `/api/stats`              | Total scans / sessions / uptime                |
| GET    | `/api/agent/health`       | Is the AI agent + Ollama reachable?            |
| GET    | `/api/agent/coach-decision`| Real LLM training decision from live vitals   |
| POST   | `/api/agent/muscle-insight`| Real LLM per-muscle coaching note             |
| POST   | `/api/agent/fuel-guidance` | Real LLM nutrition suggestion                 |
| POST   | `/api/agent/chat`         | Free-form coaching Q&A                         |

## The AI agent

Adapted from the local-Ollama pattern in
`50-AI-Engineering-Projects/09-ai-medical-imaging-agent`, but re-aimed at
fitness coaching. Guardrails keep it to training/recovery/nutrition and make
it redirect anything medical to a healthcare professional. See
`agent/README.md` for setup, config and model options.

## Changing the backend URL

If you deploy the backend somewhere other than `localhost:4000`, set this
before `main.js` loads, in `index.html`:
```html
<script>window.FITMIND_API = "https://your-backend-url.com";</script>
<script src="js/main.js"></script>
```

## Deploying

- **Backend**: any Node host works (Render, Railway, Fly.io, a VPS). Just
  needs `npm install && npm start`. `store.json` persistence assumes a
  writable filesystem — on platforms with ephemeral storage, swap it for a
  real database if you need scans to survive redeploys.
- **Frontend**: fully static — Netlify, Vercel, or GitHub Pages all work.
  Just remember to point `window.FITMIND_API` at your deployed backend URL.
